Cost estimates (API plans)

Meta gives no billing data, so the dashboard counts every model step's tokens per project folder and prices them itself. Muse reports Meta's catalog prices for each model (USD per 1 million tokens); they are used automatically and shown grey below. Type a number to override one, or fill in a model Meta does not price. With the box ticked (the default), the sidebar shows the API spend of all projects together, and each project folder shows what its API-key use has cost so far. These are estimates from token counts and prices; they can differ from Meta's bill. Use through the subscription is counted in tokens only, never in dollars.
